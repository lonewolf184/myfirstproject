# My First Project: Rock, Paper, Scissors

This is a beginner-friendly Python project where you can play **Rock, Paper, Scissors** in the terminal.

## What this project does
- Lets you choose: `rock`, `paper`, or `scissors`.
- The computer chooses randomly.
- Shows who wins each round.
- Lets you keep playing until you type `quit`.

## Run the project
1. Make sure Python 3 is installed.
2. Run:

```bash
python3 rock_paper_scissors.py
```
